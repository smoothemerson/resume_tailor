## v1.2 Requirements (All Complete)

### Prompt Precision

- [x] **PRMP-01**: `_build_messages()` system prompt defines an explicit ALLOWED list: title line, employer taglines, employer bullets, project subtitle and bullets, skills reordering/reweighting
  - **Outcome:** Delivered in Phase 12 Plan 01. `<ALLOWED>` block lists 6 elements with exact inline LaTeX patterns. Closes with "Everything not listed above must remain byte-for-byte identical."
- [x] **PRMP-02**: `_build_messages()` system prompt defines an explicit MUST-NOT-CHANGE list: candidate name, contact block, education section, languages section, employer header lines, project name/URL/date, all LaTeX structural commands
  - **Outcome:** Delivered in Phase 12 Plan 01. `<CONSTRAINTS>` block names 9 protected element types by their actual inline LaTeX patterns (e.g. `{\Huge \scshape {Name}}\\`, `\textbf{EMPLOYER}`).
- [x] **PRMP-03**: System prompt includes an anti-fabrication rule: do not substitute one named technology for another — if Azure is in the original it must appear in output; if AWS is not in the original it must not appear
  - **Outcome:** Delivered via three-layer defense in Phase 12 Plans 01+02: (1) TECHNOLOGY FIDELITY rule in `<CONSTRAINTS>`, (2) `temperature=0.2` reduces sampling variance, (3) `_check_fabricated_technologies` guard provides post-generation detection.

### Guards

- [x] **GARD-05**: `_check_technology_substitution(original, tailored)` extracts the Skills section from each text and warns when technologies are substituted, only removed, or only added
  - **Outcome:** Delivered in Phase 13 Plan 01. Uses `_extract_section` with `\header{Skills}` boundary and `_extract_technologies` with LaTeX macro stripping. Three-way warning logic: substituted / removed-only / added-only.
- [x] **GARD-06**: `_check_protected_sections(original, tailored)` warns when any of the following differ between original and tailored: contact block, education section, languages section, employer header lines, project anchors (name/URL/date)
  - **Outcome:** Delivered in Phase 13 Plan 02. Contact block via `\begin{center}...\end{center}`; Education/Languages via `_extract_section`; employer headers via `_EMPLOYER_PATTERN.findall()`; project anchors as `(url, name)` tuples from `\href{url}{\textbf{Name}}` regex.
- [x] **GARD-07**: Both new guards are called from `run_guards()` and never raise — all exceptions are caught and logged as warnings
  - **Outcome:** Delivered in Phase 13 Plan 03. `run_guards()` dispatches all 5 guards sequentially; each wrapped in `try/except Exception`.

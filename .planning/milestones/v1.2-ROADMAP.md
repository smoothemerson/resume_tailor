# Milestone v1.2: Precision & CI

**Status:** ✅ SHIPPED 2026-06-14
**Phases:** 12–14
**Total Plans:** 8

## Overview

Hardened the LLM prompt with exact allowed/protected LaTeX rules, expanded output guards to catch technology substitution and protected-section mutations, shipped GitHub Actions CI, fixed the wheel packaging gap, filled unit test coverage gaps, and removed `.claude/` from git tracking. Result: the tool's anti-fabrication posture went from "prompt-only hope" to a three-layer defense, and the codebase gained its first CI pipeline and two new deterministic guards.

## Milestone Summary

**Key Decisions:**

- Raw string literal (`r"""`) for system prompt in `llm_client.py` — new content includes `\usepackage` which is a hard `SyntaxError` in non-raw strings
- `temperature=0.2` chosen over greedy decoding — avoids degenerate repetition on full-document LaTeX rewrite with a 14B local model
- `**{"jd_technologies": ...} if analysis else {}` dict-unpacking pattern in `cli.py` — conditionally passes kwarg only when analysis is not None, preserving existing `assert_called_once_with(3 positional args)` test assertions
- `_extract_section` / `_extract_technologies` extracted as module-private helpers (Phase 13) — enables reuse by both new guards without code duplication
- Project anchors compared as `(url, name)` tuples only — excluding dates/subtitles prevents false positives on legitimate tailoring
- Pinned `astral-sh/setup-uv@v8.2.0` (full semver) — Astral stopped publishing moving major-version tags at v8.0.0 (March 2025)
- Untrack-without-delete: `git rm -r --cached` + `.gitignore` glob committed together atomically — no window where `.claude/` is untracked but not ignored

**Issues Resolved:**

- Packaging gap: `jd_analyzer.py` and `keyword_matcher.py` were missing from wheel include list since Phase 6/7 introduced them
- `.claude/` was accidentally tracked with 429 files — permanently removed from index
- UAT test 1 failure in Phase 12: root-caused to three-way fabrication risk (sampling variance + jd_analysis priming + no post-generation check); all three layers addressed in Phase 12 gap closure

**Issues Deferred:**

- `uv.lock` not committed — CI uses `uv sync` without `--locked` until lockfile is generated locally and committed
- Per-section change magnitude warning (GARD-08) — deferred to v2
- Structured output schema enforcement via Ollama `json_schema` (GARD-09) — deferred to v2
- `--no-diff` opt-in flag, persistent match history, interactive accept/reject — deferred to v2

**Technical Debt Incurred:**

- `uv.lock` absent from repo — first developer to `git clone` gets non-pinned dep resolution; resolve by running `uv lock` locally and committing

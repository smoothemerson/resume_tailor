  <action>
    Create src/diff_view.py following the guards.py single-concern module pattern (D-04):

    Imports: `import difflib` and `import sys` — no other imports, no log_manager.

    Module-level ANSI constants (no `colorama`): `_GREEN = "\033[32m"`, `_RED = "\033[31m"`,
    `_RESET = "\033[0m"`.

    Private helper `_normalize(text: str) -> str` implementing D-05: iterate `text.splitlines()`,
    apply `.rstrip()` to each line, cap consecutive blank lines at 2 (blank_count counter resets on
    non-blank lines), join with `"\n"`. Handles edge case of empty string input cleanly.

    Private helper `_colorize(line: str) -> str` implementing D-02: return `_GREEN + line + _RESET`
    when `line.startswith("+") and not line.startswith("+++")`, return `_RED + line + _RESET` when
    `line.startswith("-") and not line.startswith("---")`, otherwise return `line` unchanged. The
    `+++`/`---` guard is mandatory — omitting it causes header lines to be colored (RESEARCH.md Pitfall 2).

    Public function `show_diff(original: str, tailored: str) -> None`:
    1. TTY guard: `if not sys.stdout.isatty(): return` — implements DIFF-02
    2. Normalize both: `norm_orig = _normalize(original)`, `norm_tail = _normalize(tailored)`
    3. Call `difflib.unified_diff()` with `norm_orig.splitlines()`, `norm_tail.splitlines()`,
       `fromfile="original"`, `tofile="tailored"`, `lineterm=""` (prevents double-newline, RESEARCH.md Pitfall 1)
    4. Materialize into list: `diff = list(...)` and `if not diff: return` (prevents empty-block print, RESEARCH.md Pitfall 5)
    5. Print loop: `for line in diff: print(_colorize(line))`

    No try/except needed inside `show_diff()` — it is called outside the try/except in cli.py.
    The pure transform helpers `_normalize()` and `_colorize()` cannot raise on valid string input.
    CLAUDE.md rule: no inline comments, no docstrings.

**Goal**: Users receive warnings when the tailored resume silently drops content, introduces hallucinated fields, or breaks LaTeX formatting — without ever blocking the output file from being written

**Requirements**: GUARD-01, GUARD-02, GUARD-03, GUARD-04

Plans:

- [x] 04-03-PLAN.md — Update cli_test.py mocks for TailorResult + full suite green gate — COMPLETE 2026-06-02

**Details:**
- Built `guards.py` with three guard functions: `_check_missing_sections()`, `_check_format_violations()`, `_check_hallucinated_employers()`
- Introduced `TailorResult(content, fences_stripped)` NamedTuple to carry metadata from `llm_client.py` to `cli.py`
- Non-fatal guard pattern: each `_check_*` wraps body in `try/except Exception` so `run_guards()` never raises under any input
- All guards print to `stderr` via `logger.warning()` — never block output write

## Milestone Summary

**Key Decisions:**

- Guards are advisory-only: GUARD-04 is the architectural rule — no guard failure ever blocks output write. Keeps pipeline safe for extension.
- Diff and keyword match summary both use the same TTY predicate (`sys.stdout.isatty()`) — consistent UX rule: interactive output on TTY, clean on pipe.
- Pass-1 failure falls back silently (PIPE-03): user experience unchanged; quality may be lower but pipeline never aborts.
- `--import-mode=importlib` in pytest avoids needing `__init__.py` in test directories while resolving module name collisions.
- TailorResult NamedTuple threads metadata from `llm_client.py` to `cli.py` without global state.

**Issues Resolved:**

- Module name collision between `tests/unit/test_llm_client.py` and `tests/integration/test_llm_client.py` — resolved with `importlib` import mode
- Regex `\b` word boundary false positives (e.g., hyphenated words) — fixed with lookahead/lookbehind in `keyword_matcher.py`
- `cli_test.py` tests needed mock updates for `TailorResult` return type after Phase 4 refactor

**Issues Deferred:**

- Per-section change magnitude warning (guard against over-rewriting) — future guard
- Structured output schema enforcement via Ollama `json_schema` format field
- `--no-diff` opt-in flag — always-on with TTY guard kept simpler in v1.1

**Technical Debt Incurred:**

- Traceability table in REQUIREMENTS.md showed TEST-08/09 as "Pending" at close — documentation inconsistency (tests are complete, fixed in archive)
